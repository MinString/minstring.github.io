# 一级标题

段落之间使用空行分隔。

第二段。*斜体*、**粗体**和 `等宽字体`。列表项如下所示：

- 这个
- 那个
- 还有一个

注意，不考虑星号的话，实际文本内容从第 4 列开始。

> 引用块
> 是这样写的。
>
> 它们可以跨多个段落，
> 如果你愿意的话。

三个短线用于长破折号。两个短线用于范围（例如，"内容在第 12--14 章"）。三个点 ... 会被转换为省略号。Unicode 是支持的。☺

## 二级标题

这是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再次注意，实际文本从左边数第 4 个字符开始。下面是一段代码示例：

    # 容我重申 ...
    for i in 1 .. 10 { do-something(i) }

你可能猜到了，这缩进了 4 个空格。顺便说一句，除了缩进代码块，你也可以使用分隔符代码块：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样复制粘贴更方便）。你还可以标记代码块让 Pandoc 进行语法高亮：

```python
import time
# 快，数到十！
for i in range(10):
    # （但也不能太快）
    time.sleep(0.5)
    print i
```

### 三级标题

现在来一个嵌套列表：

1. 首先，准备好这些食材：

    - 胡萝卜
    - 芹菜
    - 小扁豆

2. 烧些水。

3. 把所有东西倒进锅里，然后按照
    以下步骤操作：

        找到木勺
        揭开锅盖
        搅拌
        盖上锅盖
        把木勺小心翼翼地搭在锅柄上
        等待 10 分钟
        回到第一步（或完成后关火）

    别碰到木勺，不然它会掉下来。

再次注意文本始终对齐在 4 个空格的缩进上（包括上面继续第 3 项的最后一行）。
