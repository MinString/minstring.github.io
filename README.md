# MinString 的博客


这是我的个人博客，也是我记录学习、折腾 Linux、编程、游戏开发以及生活思考的地方。

这个博客最初在高中时期搭建过一个简陋的版本，但因为学习繁忙，一直没有时间认真维护。高考结束后，我重新开始搭建这个博客，希望把它作为一个长期记录和分享的地方。

**博客地址：** https://minstring.github.io

## 🛠️ 技术栈

- [Astro](https://astro.build/) — 网站框架
- [Fuwari](https://github.com/saicaca/fuwari) — 博客主题
- [pnpm](https://pnpm.io/) — 包管理器
- GitHub Pages / Vercel — 部署

## 🚀 本地运行

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

启动后访问 `http://localhost:4321` 即可预览博客。

## 📦 常用命令

| 命令 | 作用 |
| --- | --- |
| `pnpm install` | 安装项目依赖 |
| `pnpm dev` | 启动本地开发服务器 |
| `pnpm build` | 构建博客到 `./dist/` |
| `pnpm preview` | 预览生产构建结果 |
| `pnpm check` | 检查代码与类型错误 |
| `pnpm format` | 使用 Biome 格式化代码 |
| `pnpm new-post <filename>` | 创建新文章 |
| `pnpm astro ...` | 执行 Astro CLI 命令 |
| `pnpm astro --help` | 查看 Astro CLI 帮助 |
