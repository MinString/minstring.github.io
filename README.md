操作指南(为了防止我忘记如何操作)

| 指令　　　　　　　　　　　 | 行为　　　　　　　　　　　　　　　　　　　　　　 |
| :---------------------------| :-------------------------------------------------|
| `pnpm install`　　　　　　 | 安装依赖　　　　　　　　　　　　　　　　　　　　 |
| `pnpm dev`　　　　　　　　 | 开一个服务器`localhost:4321`　　　　　　　　　　 |
| `pnpm build`　　　　　　　 | 构建博客 `./dist/`　　　　　　　　　　　　　　　 |
| `pnpm preview`　　　　　　 | 在提交之前，本地预览　　　　　　　　　　　　　　 |
| `pnpm check`　　　　　　　 | 检查代码错误　　　　　　　　　　　　　　　　　　 |
| `pnpm format`　　　　　　　| 用Biome格式化代码　　　　　　　　　　　　　　　　|
| `pnpm new-post <filename>` | 新建文章　　　　　　　　　　　　　　　　　　　　 |
| `pnpm astro ...`　　　　　 | Run CLI commands like `astro add`, `astro check` |
| `pnpm astro --help`　　　　| Get help using the Astro CLI　　　　　　　　　　 |
